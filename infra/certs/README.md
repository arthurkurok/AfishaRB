# Сертификаты

Положите сюда `russian_trusted_root_ca.pem` — корневой сертификат НУЦ Минцифры (Russian Trusted Root CA).
Он нужен для TLS-соединения с GigaChat API Сбера (`api.giga.chat`, `ngw.devices.sberbank.ru`).
Скачать: портал Госуслуг, раздел о сертификатах НУЦ (`https://www.gosuslugi.ru/crt`).
Файл не хранится в репозитории намеренно: обновляйте его из первоисточника.
