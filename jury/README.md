# Жюри

Десять агентов-присяжных (`.claude/agents/jury-*.md`) независимо оценивают каждый этап. Процесс описан в `docs/12-dev-loop-jury.md`, шкала и гейт — в `RUBRIC.md`.

- `reports/<этап>-r<раунд>.md` — отчёты раундов (пишет workflow `jury-review`).
- `backlog/<этап>.md` — задачи по подтверждённым замечаниям.
- `reports/artifacts/` — скриншоты и выводы команд, приложенные присяжными.
