# Текст презентации, 3 минуты

Тайминг по слайдам в скобках. Порядок слайдов совпадает с afisha.pdf.

**1. Обложка (0:00–0:10)**

Здравствуйте. Мы сделали афишу культуры Башкортостана: сайт, Telegram-бот,
админку, открытый API и виджет. Всё работает на общих данных и обновляется
каждый час. Адрес: antihype.best.

**2. Задача (0:10–0:40)**

Сейчас афишу республики собирают вручную. В 65 городах и районах анонсы
публикуют на сайтах учреждений и в соцсетях, и афиши района целиком нет
нигде. Ни один источник не отвечает на вопрос «что делать в выходные»:
даты, цены и переносы приходится сверять руками. Плюс два языка
публикации, русский и башкирский, с дублями и расхождениями.

**3. Архитектура (0:40–1:10)**

Мы собрали один контур данных. Клиенты: сайт, админка, бот с Mini App и
виджет. Сервер: модульный монолит на Fastify с открытым контрактом
OpenAPI. Данные: PostgreSQL с PostGIS, фоновые задачи на pg-boss, GigaChat
для гида. Важное справа: синк идемпотентный, дубли отсеиваются до показа,
у каждого поля события есть источник, оба языка идут из одного пакета
строк.

**4. Данные (1:10–1:30)**

В каталоге сейчас 8 703 события, 27 тысяч будущих сеансов, 2 303 площадки,
65 городов и районов. 31 процент событий бесплатные, 63 процента принимают
Пушкинскую карту. Данные синхронизируются с Культура.РФ и Башоперой
каждый час.

**5. Выбор города (1:30–1:45)**

Сайт начинается с выбора города. После него ленты, подборки и гид работают
только в рамках выбранного города.

**6. Поиск и карточка (1:45–2:00)**

Поиск с фильтрами по категории, дате, цене и Пушкинской карте. Карточка
сделана как настоящая афиша: постер два к трём, сеансы, доступность,
экспорт в календарь.

**7. Паспорт события (2:00–2:15)**

У каждого события есть паспорт: из каких лент оно собрано, уровень
доверия и история изменений по полям. Если событие перенесли, это видно.

**8. Гид (2:15–2:35)**

Гид принимает вопрос обычным языком: «куда пойти в субботу с ребёнком до
1000 рублей в Уфе». GigaChat-2 разбирает запрос, ищет по каталогу и
объясняет подборку. Ответ проверяется по базе, выдуманных событий не
бывает. Все 98 контрольных кейсов из ТЗ пройдены, есть резервный режим
правил.

**9. Админка и карта (2:35–2:45)**

В админке работает «Пульс культуры»: метрики, очередь модерации, кабинет
учреждения. На сайте есть карта площадок города.

**10. Телефон и Telegram (2:45–2:55)**

Сайт адаптивный, отдельной версии не нужно. Mini App открывается из бота
@AfishaRB102bot: афиша, подписки и дайджесты прямо в Telegram.

**11. Что открыто (2:55–3:00)**

Всё доступно: сайт, документация API, бот, админка, конструктор виджета
и код на GitHub.

**12. Финал**

Отсканируйте QR или откройте antihype.best. Спасибо!

## Ответы на вероятные вопросы

- **Откуда данные?** PRO.Культура.РФ и учреждения культуры РБ. Коннекторы
  идемпотентные, синк каждый час, при сбое возобновляется.
- **Как боретесь с дублями?** Автопарсер скорит пары-кандидаты, спорные
  уходят в очередь модерации в админке.
- **Пушкинская карта?** 63 процента событий помечены, есть фильтр в поиске.
- **Башкирский язык?** Полный перевод интерфейса, antihype.best/ba. Строки
  из одного пакета i18n, плюрализация по правилам CLDR.
- **Что если GigaChat недоступен?** Гид переключается на детерминированный
  режим правил: разбор запроса без модели, подборка по фильтрам.
- **Почему monolith?** Один контур данных на пять клиентов, деплой одним
  стеком. Разделение по модулям внутри, контракт OpenAPI зафиксирован.
