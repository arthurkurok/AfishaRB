## 1. Общая модель поиска (одинакова во всех каналах)

### 1.1. Категории — «зонтик курая»

Верхний уровень навигации — 7 категорий. Их визуализирует фирменный навигатор «зонтик курая» (см. 07-design §7). Семилепестковый цветок в круге не используется — это элемент госсимволики РБ.

| № | Категория | Подкатегории (примеры) |
|---|---|---|
| 1 | Театр | драма, опера и балет, кукольный, мюзикл, оперетта, стендап (если есть) |
| 2 | Музыка | академическая, народная, эстрада и рок, джаз, хоры, органная |
| 3 | Музеи и выставки | постоянные экспозиции, временные выставки, экскурсии, ночь музеев |
| 4 | Детям | спектакли, мастер-классы, интерактив, кружки на один день |
| 5 | Народная культура и праздники | Сабантуй, Йыйын, Ҡаҙ өмәһе, фольклор, ремёсла, национальные праздники, фестивали |
| 6 | Кино | премьеры, фестивальное кино, кино на башкирском, кинолектории |
| 7 | Лекции и встречи | лекции, мастер-классы, литературные вечера, библиотечные события, клубы |

Сквозные теги (не категории): «бесплатно», «под открытым небом», «на башкирском языке», «премьера», «последний шанс», «впервые в городе», «для всей семьи».

### 1.2. Фильтры (требование ТЗ T5)

| Фильтр | Значения | Детали |
|---|---|---|
| **Дата** | сегодня, завтра, выходные, эта неделя, календарь (диапазон); время суток: утро, день, вечер | Вычисляется в `Asia/Yekaterinburg`. «Выходные» в пятницу после 18:00 — ближайшие сб–вс, в воскресенье после 18:00 — следующие |
| **Город / место** | муниципалитет (54 района + городские округа), населённый пункт, «рядом со мной» + радиус 1/3/10/30 км, конкретная площадка | Поиск по ru и ba названиям и синонимам (Өфө = Уфа). По умолчанию — последний выбранный город или геопозиция с согласия |
| **Цена** | бесплатно, до 500 / 1000 / 2000 ₽, свой диапазон | Событие подходит, если хотя бы часть билетов ≤ порога. Карточка показывает «от N ₽» |
| **Возраст** | возрастной знак 0+/6+/12+/16+/18+; режим «с ребёнком N лет» | «С ребёнком 5 лет» = знак ≤ 0+ **и** нет пометки «не рекомендовано детям». События 18+ скрыты по умолчанию в режиме «с ребёнком» |
| **Категория** | 7 категорий + подкатегории + теги | Множественный выбор |
| Пушкинская карта | да/нет | Отдельный режим для 14–22 лет |
| Доступная среда | для колясок, для незрячих (тифлокомментирование), для неслышащих (РЖЯ, субтитры), индукционная петля, для людей с ментальными особенностями | Только если данные есть в источнике или от учреждения |
| Язык мероприятия | русский, башкирский, татарский, другой | — |
| Скрыть распроданные | да/нет | По умолчанию распроданные показываются в конце с пометкой |

### 1.3. Сортировка

«Подходящие» (по умолчанию, объяснимый скоринг), «По дате», «Сначала дешёвые», «Ближе ко мне», «Популярные». Правила ранжирования «Подходящих» опубликованы на странице «Как работают рекомендации».

### 1.4. Представления выдачи

- **Лента:** карточки, сгруппированные по дням с липкими заголовками «Сегодня», «Завтра», «Суббота, 8 ноября».
- **Карта:** кластеры, «искать в этой области», карточка-превью снизу.
- **Таймлайн дня:** горизонтальная шкала времени — видно, что можно успеть за день.
- **Календарь месяца:** плотность событий по дням (тепловая подсветка).

### 1.5. «Паспорт события» — карточка события

Обязательные элементы:
1. Обложка (с лицензией) или фирменная иллюстрация категории, если изображения нет.
2. Название, категория, **возрастной знак (всегда)**, **статус-бейдж** (если не «по плану»).
3. Ближайший сеанс: дата, время, площадка; «ещё 5 дат» разворачивает список сеансов со статусами каждого.
4. Цена «от–до», кнопки билетов (основной продавец + альтернативы), бейдж Пушкинской карты.
5. Площадка: адрес, мини-карта, «Маршрут» (Яндекс Карты или 2ГИС на выбор), телефон кассы, иконки доступности.
6. Описание (свернуть/развернуть), язык мероприятия, длительность, организатор.
7. **Блок «Паспорт»:** источники («PRO.Культура.РФ», «Сайт театра», «Кабинет учреждения»), «Проверено 40 мин назад», уровень доверия, история изменений: «Перенесено с 12 на 19 ноября (сообщил театр, 2 ноября)».
8. Действия: в избранное, напомнить, в календарь (.ics), поделиться (карточка-картинка для сторис), «Спросить Гида об этом событии», «Сообщить о неточности».
9. «Похожие» и «Рядом в этот же день».
10. JSON-LD `schema.org/Event` (веб) с `eventStatus` (`EventScheduled`, `EventRescheduled`, `EventCancelled`, `EventPostponed`).

### 1.6. Отображение статусов

| Статус | Бейдж | Поведение |
|---|---|---|
| По плану | — | Обычная карточка |
| Мало билетов | «Осталось мало билетов» (янтарный) | Только если источник сообщает |
| Распродано | «Билетов нет» (серый) | В конец выдачи; кнопка «Сообщить, если появятся» (если источник поддерживает) |
| Перенесено | «Перенесено → 19 ноября» (синий) | Старая дата зачёркнута, ссылка на новый сеанс; подписчики получают уведомление |
| Отложено | «Перенесено, новая дата уточняется» | Исключено из ИИ-подборок |
| Отменено | «Отменено» (красный) | Видно 7 дней по прямой ссылке и в избранном, из поиска исключено; уведомление подписчикам |
| Завершено | «Прошло» | Видно по прямой ссылке (SEO), из поиска исключено |
| Уточняется | «Информация уточняется» | Событие исчезло из источника — до решения модератора понижается и исключается из ИИ-подборок |

Доступность — по ПП РФ № 102 от 07.02.2026 (масштаб 200 % без горизонтальной прокрутки, контраст 4,5:1, клавиатура, альтернативный текст, подписи полей) и WCAG 2.2 AA. Отдельная «версия для слабовидящих» не обязательна; вместо неё есть настройка «Крупный текст и высокий контраст» в шапке.

## 3. Telegram-бот

### 3.1. Онбординг (`/start`)

1. Приветствие маскота (стикер) и выбор языка: Русский / Башҡортса.
2. Город: кнопки топ-8 городов + «Другой» (ввод с подсказками) + «Отправить геопозицию».
3. «С кем обычно ходите?»: один / с детьми / с друзьями / пропустить. Если с детьми — возраст (кнопки).
4. Сразу показываем «Сегодня в {город}» и подсказку: «Напишите своими словами, что ищете».

Онбординг пропускается одной кнопкой. Всё можно поменять в `/settings`.

### 3.2. Главное меню (постоянная клавиатура)

`🎭 Сегодня` · `📅 Выходные` · `✨ Подобрать` · `🗂 Категории` · `📍 Рядом` · `⭐ Избранное` · `⚙️ Настройки` + кнопка Mini App «Открыть афишу».

### 3.3. Свободный текст → Гид

Любое сообщение, не совпадающее с командой, уходит ИИ-гиду (05). Голосовые сообщения распознаются (этап 2).

### 3.4. Карточки в боте

Фото + подпись (название, дата, площадка, цена, возраст, статус) + кнопки `Подробнее` (раскрывает в том же сообщении), `🎟 Билеты` (URL), `⭐`, `🔔 Напомнить`, `📤 Поделиться`. Листание выдачи — `◀ 2/7 ▶` с редактированием сообщения, а не новыми сообщениями.

### 3.5. Уведомления

- Изменения по избранному: перенос, отмена, смена площадки, распродано.
- Напоминания: за день и за 3 часа.
- Дайджест по подписке: день недели и время выбирает пользователь, по умолчанию четверг 18:00.
- Тихие часы 22:00–09:00 по TZ региона.
- Каждое уведомление содержит «Отписаться от такого».

### 3.6. Inline-режим

`@bot театр выходные` в любом чате → список карточек для отправки. Готовый механизм «скинуть другу».

### 3.7. Групповые чаты

Бота добавляют в семейный или дружеский чат: `/kuda суббота` → 3–5 вариантов + опрос «Куда идём?». Итог опроса → кнопка «Напомнить всем, кто голосовал».

### 3.8. Mini App

Полный веб-интерфейс внутри Telegram (маршруты `/tma`): тема Telegram, `BackButton`, `MainButton`, haptic feedback, авторизация по `initData` (проверка подписи на сервере).

### 3.9. Команды

`/start`, `/today`, `/weekend`, `/near`, `/fav`, `/subs`, `/settings`, `/lang`, `/nopersonal`, `/help`, `/about` (источники и достоверность), `/privacy`.

## 4. Другие мессенджеры

Не планируются: единственный мессенджер-канал — Telegram (бот, Mini App, inline-режим, группы). Ядро диалога не зависит от канала (04 §9), поэтому другой мессенджер при необходимости подключается одной новой реализацией адаптера.

## 5. ИИ-гид

Полностью описан в [05-ai-agent.md](05-ai-agent.md). Доступен в боте (свободный текст), на сайте (строка на главной + страница Гида), в Mini App, в мобильных приложениях и в виджете (опционально, флаг `ai="true"`).

## 6. Открытый API, виджет, документация, открытые данные (T12–T15)

### 6.1. API — см. 04-architecture §8.

### 6.2. Виджет

```html
<script src="https://cdn.<домен>/widget/v1/afisha.js" type="module" async></script>
<afisha-rb
  municipality="ufa"
  categories="theatre,music"
  layout="carousel"
  limit="8"
  lang="ru"
  theme="auto"
  accent="#0F6E4F"
  ai="false">
</afisha-rb>
```

- Раскладки: `carousel`, `list`, `grid`, `calendar`, `compact` (для сайдбара).
- Параметры: муниципалитет, площадка, учреждение, категории, теги, бесплатно, Пушкинская карта, возраст, лимит, язык, тема (`light`/`dark`/`auto`), акцентный цвет, скругления, показывать ли Гида.
- Изоляция: Shadow DOM, без глобальных стилей, без cookies и localStorage, без сторонних трекеров. Нет новых требований к баннеру cookie на сайте министерства.
- Фоллбэк для строгой CSP или платформ без пользовательского JS: `<iframe src="https://<домен>/embed?...">` с автоподбором высоты через `postMessage`.
- Доступность: навигация с клавиатуры, ARIA, контраст, `prefers-reduced-motion`.
- Конструктор на сайте: выбрать параметры → живой предпросмотр → «Скопировать код», а также инструкции для 1С-Битрикс, WordPress, Tilda и платформы госсайтов (если на ней можно вставить HTML-блок).
- **Виджет для учреждений** — тот же код с фильтром `organization="..."`. Театр бесплатно получает афишу на свой сайт, а значит заинтересован поддерживать свои данные в системе актуальными. Это двигатель качества данных.

### 6.3. Документация

- `/developers`: обзор, быстрый старт за 5 минут, интерактивный справочник (из OpenAPI), примеры (curl, JavaScript/TypeScript, PHP — для Битрикса), лимиты, лицензия данных, changelog, статус-страница.
- PDF-инструкция «Подключение виджета к сайту министерства» на 2 страницы для ИТ-отдела.

### 6.4. Открытые данные и фиды

- Ежедневные выгрузки (CSV, JSON) с паспортом набора данных по методическим рекомендациям для открытых данных.
- iCal: по площадке, учреждению, муниципалитету, сохранённому поиску.
- RSS по муниципалитету и категории (для СМИ и пабликов).

| Виджет | Готовый сниппет афиши учреждения для своего сайта |

## 8. Модерация и редакция (для министерства)

- **Очереди:** новые события из источников с низким доверием (извлечённые ИИ, агрегированные без подтверждения); сомнительные дубли (бок о бок, кнопки «Объединить» / «Разные»); жалобы пользователей; «исчезнувшие» события; ошибки источников.
- **Карточка задачи:** исходник (ссылка, скриншот поста, сырой JSON) рядом с извлечёнными полями, подсветка расхождений, горячие клавиши.
- **Редакция:** подборки, баннеры на главной, «событие недели», тексты на ru и ba.
- **Здоровье источников:** последний успешный сбор, число записей, ошибки, свежесть по каждому источнику и учреждению.
- **Аудит:** кто, что и когда изменил (append-only).
- **Роли (RBAC):** супер-админ, модератор министерства, редактор подборок, аналитик (только чтение), администратор и редактор учреждения.

## 9. Дашборд министерства «Пульс культуры»

| Блок | Показатели |
|---|---|
| Предложение | События по районам, категориям и неделям; доля бесплатных, по Пушкинской карте, доступных, на башкирском; новые учреждения в системе |
| **Спрос** | Запросы к поиску и Гиду (обезличенно): топ тем, география, время. **«Спрос без предложения»** — кластеры запросов с пустой выдачей: «детские спектакли в Нефтекамске на выходных — 210 запросов, 0 событий» |
| Вовлечённость | Аудитория по каналам (бот, веб, iOS, Android, виджет), просмотры карточек, клики на билеты, подписки |
| Качество данных | Индекс полноты по учреждениям и районам, свежесть, доля карточек без фото или без цены, рейтинг учреждений |
| Отчёты | Выгрузка в Excel/PDF за период для ведомственной отчётности; ежемесячный автоотчёт на email |

## 10. Аккаунты, избранное, подписки

- Всё доступно без регистрации. Аккаунт нужен для синхронизации между каналами. Вход — только российскими способами (ст. 8 149-ФЗ): телефон, VK ID, Яндекс ID, позже ЕСИА. Telegram-бот связывается с аккаунтом одноразовым кодом.
- Избранное (события и площадки), подписки на сохранённые поиски, напоминания, история.
- Настройки уведомлений по каналу: push, Telegram, email.
- Экспорт и удаление своих данных одной кнопкой.

## 11. Культурный дневник (геймификация)

- Отметка «Я был» доступна только в окне события и при геопозиции рядом с площадкой (±300 м) или по QR-коду на площадке. Без проверки достижение не засчитывается: никакой накрутки.
- Коллекция «узоров»: за каждую категорию — фрагмент башкирского орнамента. Собрал 7 — получаешь полный узор-медальон (шеринг-карточка).
- Достижения: «Театрал сезона», «Знаток районов» (события в 5 разных районах), «Ҡурай» (5 событий народной культуры).
- «Культурный итог года» в декабре: персональные сторис со статистикой.
- Никаких денежных призов и рейтингов людей — только личная коллекция (снимает риски и ПДн-нагрузку).
