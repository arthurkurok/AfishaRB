# 07. Бренд, дизайн-система, UX

> Концепция — «**Живой орнамент**»: башкирская геометрия как структура интерфейса, а не как декор поверх него. Современно, тепло, узнаваемо. Без «этно-сувенирности» и без госсимволики.
> Факты о мотивах, символике и шрифтах проверены 02.11.2026 (источники в конце).

## 1. Исходные решения и ограничения

| Решение | Почему |
|---|---|
| Основа — орнамент **ҡусҡар** (завиток «улитка»: росток, рога, волна, солнце — «символ жизненной силы рода») и **ромб** («плодородие, животворящее начало») | Мотивы описаны в Башкирской энциклопедии. После принятия ислама орнамент стал стилизованным и абстрактным, так что геометрия здесь исторически оправдана |
| **Не используем** семилепестковый цветок курая в золотом круге, флаг, герб | Это элементы госсимволики (Закон РБ № 10-з, ст. 10, 26, 28–29): для символики юрлиц с такими элементами нужна экспертиза Комиссии по госсимволике |
| Курай — только как **зонтик-соцветие** (растение курай — зонтичное) с лучами, без круга и без семи одинаковых лепестков | Узнаваемо, но без претензии на эмблему |
| Палитра — красный, жёлтый, зелёный на чёрном бархате и светлом холсте | Подтверждённые цвета башкирского костюма и вышивки (красный, жёлтый, зелёный; фон часто красный, жёлтый или чёрный) |
| Пчела-маскот — **без жёлто-чёрных полос** | Жёлто-чёрная полоса прочно связана с «Билайном» |
| Шрифты только с полным набором башкирских букв (Ә Ғ Ҙ Ҡ Ң Ө Ҫ Ү Һ) | Manrope, Unbounded, Jost, Sofia Sans, Russo One и др. **не подходят** — в них нет этих знаков |

## 2. Название

| Вариант | Плюсы | Минусы |
|---|---|---|
| **«Тамаша»** (баш. «зрелище, представление») | Точный смысл, читается по-русски без особых букв | В Казахстане есть театр и ТВ-бренд «Тамаша» |
| **«Бал»** («мёд» по-башкирски, «бал» по-русски) | Двуязычная игра слов, связь с пчелой | Обычное слово: сложно зарегистрировать, шум в поиске |
| «Торна» (журавль; «Сыңрау торна» — сказка, песня и балет 1944 года) | Коротко, свободно | Менее очевидно |
| «Йыйын» | Идеальный смысл | **Политически чувствительно** (дело запрещённой организации «Башкорт», 2020). Используем только как название рубрики традиционных праздников |
| «Курай» | Сильный символ | Слишком близко к госэмблеме |

**Рекомендация:** «**Тамаша** · Афиша культуры Башкортостана» — официальное полное имя для министерства + короткий бренд. Маскот — пчела **Бал**. До питча — проверка в ФИПС по классам 9, 35, 38, 41, 42 (задача владельца). Если «Тамаша» не проходит — «Торна». В документах и коде продукт называется «Афиша культуры РБ» (`afisha`), бренд подставляется из конфигурации региона.

## 3. Маскот — пчела Бал

**Роль:** проводник ИИ-Гида. Как и у Робота Макса на Госуслугах, у маскота есть работа: он появляется там, где Гид думает, находит, уточняет или честно говорит «не нашёл». Это не украшение.

**Легенда:** бурзянская бортевая пчела из Шульган-Таша. Пчела собирает нектар с тысяч цветков, Бал собирает события с тысяч площадок республики. Метафора агрегатора, понятная ребёнку.

**Внешность (бриф для иллюстратора — в 13-owner-tasks):**
- тело тёплого медового янтаря (#F4A51C → #E8A92E), без чёрных полос; полоски заменены тонким орнаментальным пояском ҡусҡар цвета коралла (#B8322A);
- крылья полупрозрачные, с прожилками-ромбами;
- большие внимательные глаза, лёгкая улыбка; маленький коралловый шарф или тюбетейка-намёк — **опционально**, без карикатурной «национальности»;
- силуэт читается в 24 × 24 px (иконка бота) и в 512 × 512 (онбординг).

**Характер:** любопытная, доброжелательная, немногословная. Обращается на «вы». Шутит редко и мягко. Никогда не поучает.

**Набор эмоций (12):** приветствие (машет), думает (кружит), нашла (держит карточку), уточняет (наклон головы, знак вопроса из ромбов), не нашла (разводит лапками, но протягивает «альтернативу»), праздник (конфетти-ромбы), ночь (спит в соте), ошибка сети (ищет сигнал), загрузка (полёт по траектории-завитку), напоминание (колокольчик), достижение (медальон-узор), «спасибо за отзыв».

**Где маскота нет:** в уведомлениях об отмене и переносе (серьёзный тон), в кабинете учреждения и админке (рабочий инструмент), в документации API.

**Запасной персонаж:** журавль Торна — для театральной линии и спецпроектов.

## 6. Форма

- **Ромб** — главный графический атом: дата в ромбе, бейджи статуса, маркеры на карте, буллеты.
- **Срез ҡусҡар** — у постера в карточке события один угол срезан завитком (маска SVG/Shape). Это узнаваемый «почерк» продукта.
- **Кайма** — 4 px снизу карточки в цвете категории, как орнамент по краю одежды (ворот, рукава, подол).
- Радиусы: `radius.s` 8, `radius.m` 14, `radius.l` 22, `radius.pill` 999. Сетка отступов — 4 pt: 4, 8, 12, 16, 24, 32, 48.
- В Compose ҡусҡар-срез и ромб реализуются как собственные `Shape` (по аналогии с `MaterialShapes`), в SwiftUI — как `Shape`. Готовую `Cookie7Sided` в золоте не используем: это почти эмблема.

## 7. Фирменные компоненты

| Компонент | Описание | Где |
|---|---|---|
| **Карточка события** | Постер со срезом ҡусҡар; дата в ромбе (день крупно, месяц и время мелко); название (2 строки); площадка и район; чипы «от 400 ₽», «0+», бейдж Пушкинской карты; кайма категории; статус-бейдж. Состояния: обычное, отменено (постер обесцвечен, ромб перечёркнут), перенесено, прошло, скелетон | Все каналы |
| **Зонтик курая** | Навигатор категорий: лучи зонтика расходятся от точки, на концах лучей — иконки категорий в ромбах. Тап по лучу — фильтр; долгий тап — подкатегории. На мобильном — горизонтальная лента «лучей» | Главная, поиск |
| **Паспорт события** | Блок доверия: источники в виде «печатей», «проверено 40 мин назад», вертикальная лента истории изменений с ромбами-узлами | Карточка события |
| **Чипы понимания** | Над выдачей Гида: «Суббота, 8 ноября · Уфа · Ребёнок 5 лет · До 1000 ₽ за билет». Сплошной контур — сказано пользователем, пунктир — достроено; тап — изменить | Гид во всех каналах |
| **Чипы причин** | Под карточкой в подборке Гида: «0+ — подходит по возрасту», «до 1000 ₽», «в 11:00» — из `reason_codes` | Гид |
| **Таймлайн дня** | Горизонтальная шкала времени с блоками событий и переходами между ними | Маршрут дня, поиск |
| **Карта республики** | Стилизованные контуры районов с подсветкой активности (без политической раскраски) | Главная, дашборд |
| **Медальон дневника** | Круговой орнамент, который складывается из 7 фрагментов (по фрагменту за категорию) | Культурный дневник |

## 8. Иллюстрации и иконки

- **Иконки:** линейные, 2 px, скругления 1 px, сетка 24 px. Мотивы категорий — из таблицы 4.2. Системные иконки — SF Symbols на iOS, Material Symbols на Android, собственный набор в вебе.
- **Иллюстрации категорий** (7 шт., используются как обложка, если у события нет фото): плоская геометрия, 3–4 цвета палитры, орнаментальный паттерн, без людей с узнаваемыми лицами. Формат 16:9 и 1:1, SVG + PNG@2x.
- **Пустые состояния** — маскот + одна фраза + одно действие.

## 9. Движение

- Токены: `motion.fast` 120 мс, `motion.base` 220 мс, `motion.slow` 360 мс; кривая `cubic-bezier(.2,.8,.2,1)`.
- Фирменная анимация: загрузка — пчела летит по спирали-ҡусҡару; «добавить в избранное» — ромб наполняется мёдом.
- `prefers-reduced-motion` / Reduce Motion / «Убрать анимации» → только смена прозрачности.
- Не больше 3 вспышек в секунду (ПП 102).

## 10. Голос и тон

Гид говорит как знающий местный житель: дружелюбно, конкретно, на «вы», без канцелярита. Одна мысль — одно предложение.

| Ситуация | Так | Не так |
|---|---|---|
| Нашли | «Нашёл 4 варианта на субботу в Уфе. Два спектакля для малышей — с утра.» | «По вашему запросу найдены следующие мероприятия:» |
| Не нашли | «В субботу до 1000 ₽ ничего для пятилетних нет. В воскресенье есть два спектакля — показать?» | «К сожалению, ничего не найдено.» |
| Уточнение | «1000 ₽ — это на билет или на всех?» | «Пожалуйста, уточните бюджетные параметры.» |
| Отмена | «Спектакль „Буратино“ 8 ноября отменён театром. Деньги за билеты возвращает касса — телефон ниже.» | «Упс! Мероприятие отменено 😢» |
| Ошибка | «Не получается связаться с сервером. Избранное доступно без сети.» | «Ошибка 503.» |

Башкирские тексты (интерфейс, фразы Гида) готовит команда с помощью ИИ (Claude) и самопроверяет по словарям и корпусу Bashkorttele. Автоматического перевода интерфейса «на лету» нет; в описаниях событий машинный перевод допустим только с пометкой «машинный перевод». После запуска приглашаем носителей языка к правкам (§12).

## 11. Доступность (обязательные правила)

- ПП РФ № 102 и WCAG 2.2 AA: контраст токенов проверяется в CI; масштаб 200 % без горизонтальной прокрутки; полная работа с клавиатуры; видимое кольцо фокуса (`color.focus`, 2 px + 2 px отступ); подписи у всех полей; alt у изображений (по умолчанию — «Афиша: {название}»).
- Касание — не меньше 44 × 44 pt (iOS) и 48 × 48 dp (Android и веб).
- Dynamic Type до AX5 и масштаб шрифта 200 % — вёрстка карточек перестраивается в вертикальную.
- Режим «Крупный текст и высокий контраст» (веб, шапка) и режим «Просто» (приложения).
- Скринридер: карточка читается одной фразой: «Спектакль „Буратино“, 0+, суббота 8 ноября, 11:00, театр кукол, от 400 рублей, мало билетов».

## 12. Двуязычие ru / ba

- Переключатель языка — в шапке и в онбординге, запоминается.
- `lang="ba"` у башкирского контента; в приложениях — локаль `ba`. Если системная локаль `ba` не поддерживается ОС, используется собственный переключатель внутри приложения.
- Башкирские строки длиннее русских на 10–30 %: макеты проверяются на ba, снапшот-тесты — в обоих языках.
- Названия месяцев и дней недели, плюрализация — CLDR, где данные для `ba` есть; остальное — собственный словарь, сверенный со словарями и корпусом Bashkorttele.
- В разделе «О проекте» на ba — пометка, что перевод выполнен командой и правки принимаются; кнопка «Предложить правку перевода».
- Топонимы: двойные названия (Өфө / Уфа) в справочнике; поиск понимает оба варианта.

## 14. Дизайн-токены

Формат W3C DTCG в `packages/design-tokens/tokens/*.json` → Style Dictionary → CSS custom properties, `Tokens.swift`, `Tokens.kt`.

```json
{
  "color": {
    "accent": { "$type": "color", "$value": "#B8322A", "$extensions": { "mode": { "dark": "#F07A68" } } },
    "category": {
      "theatre": { "$type": "color", "$value": "#B8322A" },
      "music":   { "$type": "color", "$value": "#2E64A8" }
    }
  },
  "radius": { "m": { "$type": "dimension", "$value": "14px" } },
  "motion": { "base": { "$type": "duration", "$value": "220ms" } }
}
```
