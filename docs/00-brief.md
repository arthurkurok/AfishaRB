# 00. Исходное ТЗ (дословно)

> Министерство культуры Республики Башкортостан
> **Афиша культуры Башкортостана**
> Telegram-бот + веб-сервис + REST API + ИИ-агент
>
> *Чат-боты · Веб-платформы · ИИ-системы*
>
> Единая достоверная афиша культурных событий республики: Telegram-бот и веб-сервис с поиском и фильтрами по дате, городу, цене, возрасту и категории, статусами событий и дедупликацией — выдуманных мероприятий нет. ИИ-агент разбирает свободный запрос («куда пойти в субботу с ребёнком до 1000 рублей»), задаёт уточнения и объясняет подборку. Открытый REST API, виджет и документация для подключения к сайту министерства — без вмешательства в его действующие системы.

## Дополнительные требования команды

- Не MVP, а полноценный продукт, готовый к эксплуатации.
- Уникальный дизайн и UI/UX, нестандартные архитектурные решения.
- ИИ — **GigaChat**.
- Нативные мобильные приложения: iOS (Swift) и Android (Kotlin). Flutter и другие кроссплатформенные UI-фреймворки не используются.
- Бэкенд и все веб-части — только на TypeScript (Node.js): решение владельца продукта от 02.11.2026 (ADR-014).
- Процесс: «разработали → проверили агентами-жюри → доделали → проверили» по кругу до прохождения гейта (`docs/12-dev-loop-jury.md`).
- Заготовки кода разрешены организаторами: продукт разрабатывается с 02.11, на хакатоне — адаптация под полное ТЗ, доводка, демо и защита (`docs/11-roadmap.md`).
