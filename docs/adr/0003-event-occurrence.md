# ADR-003. Событие (Event) отдельно от сеанса (Occurrence), статус — на уровне сеанса

Статус: принято

**Решение.** `event` — произведение/мероприятие, `occurrence` — конкретный сеанс со статусом (`scheduled | rescheduled | postponed | cancelled | sold_out | unverified | ended`). Длинные серии ежедневных сеансов одной площадки (> 45, выставки) сворачиваются в один интервал `is_range`. Сеансы хранятся в горизонте 180 дней.

**Последствия.** Перенос одного показа не ломает остальные; в выдаче сеансы одного события сворачиваются в карточку «ещё N дат».
