# ADR-001. Модульный монолит на TypeScript (Fastify) с точками входа api / bot / worker

Статус: принято (02.11.2026; язык уточнён в ADR-014)

**Контекст.** Небольшая команда, сопровождение министерством, возможная аттестация ИС. Нужны строгие границы ответственности без накладных расходов микросервисов.

**Решение.** Один пакет `apps/api`, модули в `src/modules/<name>/` с публичным `index.ts`. Три процесса из одной кодовой базы: `api` (HTTP), `bot` (Telegram + отправка уведомлений), `worker` (pg-boss: синхронизация, жизненный цикл). Границы проверяет dependency-cruiser (`.dependency-cruiser.cjs`) в `make check`.

**Последствия.** Один образ, один деплой; модуль можно вынести в сервис, не переписывая соседей. Цена — дисциплина импорта, которую контролирует CI.
