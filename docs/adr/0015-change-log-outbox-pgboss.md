# ADR-015. change_log как outbox уведомлений, pg-boss — для расписаний

Статус: принято

**Контекст.** Уведомление об отмене должно уйти подписчикам ≤ 15 минут, ровно один раз, даже при перезапусках.

**Решение.**
- Outbox — сам журнал `change_log` (колонка `notified`). Процесс бота забирает необработанные записи `FOR UPDATE SKIP LOCKED` раз в 10 секунд и отправляет через зарегистрированный транспорт канала. Идемпотентность — уникальный ключ `notification(profile_id, change_id)`.
- Регулярные задачи (синхронизация источника каждые 6 ч, `ended` каждые 5 мин, производные поля ежечасно) — pg-boss с cron в часовом поясе региона и политикой очереди `singleton`.

**Почему так.** Отправка требует клиента Telegram, который живёт в процессе бота; журнал уже транзакционен и не требует второй очереди. Проверено тестом «отмена в кабинете → уведомление → без дубля».
