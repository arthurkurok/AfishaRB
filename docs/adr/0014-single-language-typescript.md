# ADR-014. Единый язык TypeScript для бэкенда и веба

Статус: принято (решение владельца продукта, 02.11.2026)

**Решение.** Бэкенд и все веб-части — TypeScript на Node.js; мобильные — Swift и Kotlin. Go рассматривался и отклонён: общий язык позволяет импортировать схемы контракта напрямую в веб, виджет и админку. Ранние заготовки бэкенда перенесены на TypeScript.
