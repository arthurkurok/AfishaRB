# ADR-006. ИИ не источник фактов: выбор только из кандидатов + верификатор

Статус: принято

**Решение.** Даты, цены, возраст и города разбирает детерминированный парсер; GigaChat дополняет тематику и намерение. Поиск — по БД. Модель выбирает только из переданных ID и пишет короткие объяснения; каждое объяснение проходит `verifier.ts` (время, цены, возраст, даты, дни недели, названия, оценочные слова). Чужой ID отбрасывается, ложная фраза заменяется шаблоном, инцидент пишется в `assistant_trace`. Без GigaChat — режим правил.

**Проверка.** Тест с подставным «галлюцинирующим» провайдером; eval: 0 нарушений на провокациях.
