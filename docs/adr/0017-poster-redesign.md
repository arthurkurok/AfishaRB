# ADR-017. Постерный редизайн: без маскота, Leaflet-карта, Golos Text

Статус: принято

**Контекст.** Первый виток дизайна опирался на «народные мотивы» (маскот-пчела, ромбы в датах, каймы категорий, схематичная карта республики) и два шрифта. Обзор показал, что продукт выглядит архаично рядом с современными афишами (Яндекс Афиша и т.п.): карточки перегружены декором, иерархия слабая, карта не даёт представления о реальной географии.

**Решение.**
- **Карточка события — постер 2:3.** Обложка обрезается в соотношении 2:3, дата-строка окрашивается цветом категории, каймы и ромбы из карточек убраны. Ромб остаётся только в логотипе.
- **Один шрифт — Golos Text** (OFL, полная башкирская кириллица). Commissioner удалён. Акцентный вес — 700.
- **Палитра:** фон `#F7F6F3`, акцент `#C33124` (контраст к белому 5.55:1, к фону 5.16:1 — AA для текста), радиусы 10/14/18, тени мягкие двухуровневые. Сетка карточек 232px, рейл 208px.
- **Маскот удалён полностью.** Пустые состояния — одна фраза + одно действие; в чате Гида — аватар-иконка и индикатор «печатает» из трёх точек; в OG-картинке — SVG-ромб логотипа.
- **Карта — Leaflet + OpenStreetMap.** Маркеры-круги в центрах муниципалитетов, размер ~ числу предстоящих событий, клик ведёт на страницу города. Заменяет схематичную SVG-оболочку. API — строковый `hrefBase` вместо колбэка `hrefFor` (функцию нельзя передать из серверного компонента в клиентский).

**Почему так.** Декор конкурировал с контентом: на постерных лентах современные афиши показывают обложку и минимальную подпись, всё остальное — шум. Схематичная карта не читалась как Башкортостан; OSM-подложка узнаваема бесплатно и без ключей. Маскот не пережил тест «выглядит профессионально?» — replacing его иконкой дешевле, чем рисовать 11 эмоций.

**Последствия.** `packages/design-tokens` перегенерирован (контраст-чек 45 пар OK); `mascot.tsx` и `kurai-umbrella*` удалены; `leaflet` добавлен в зависимости web.
