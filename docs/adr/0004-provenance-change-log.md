# ADR-004. Provenance на уровне поля и append-only журнал изменений

Статус: принято

**Решение.** `field_provenance` — источник, запись источника и время наблюдения для каждого поля события. `change_log` — неизменяемый журнал: создание, изменение полей, переносы, смена статусов, слияния и разъединения дублей. Из журнала строится «история изменений» в паспорте события и уведомления подписчикам.
