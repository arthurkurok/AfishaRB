# ADR-002. PostgreSQL как единое хранилище: FTS, pg_trgm, pgvector, PostGIS, очередь

Статус: принято

**Решение.** Каталог, полнотекстовый поиск (`tsvector`, русская морфология), опечатки (`pg_trgm`), семантика (`halfvec` pgvector, EmbeddingsGigaR 2560 изм.), гео (PostGIS geography), очередь и cron (pg-boss, схема `pgboss`) — в одной PostgreSQL. Valkey — только для короткоживущего состояния (диалоги Гида).

**Почему.** Объём региона — десятки тысяч событий; замер на полном каталоге РБ (8,5 тыс. событий, 26 тыс. сеансов): поиск с фильтрами 13–52 мс. Один компонент для бэкапа и аттестации.

**Пересмотр.** OpenSearch — если p95 поиска > 300 мс или сеансов > 500 тыс. (ADR-007).
