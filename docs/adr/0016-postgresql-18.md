# ADR-016. PostgreSQL 18

Статус: принято

**Решение.** PostgreSQL 18 (+ PostGIS 3, pgvector 0.8) — встроенная функция `uuidv7()` для сортируемых по времени первичных ключей. Образ: официальный `postgres:18-bookworm` + пакеты PGDG (мультиарх; `postgis/postgis` не собран под arm64).

**Требование к облаку.** Управляемый PostgreSQL 18 с расширениями PostGIS и pgvector; при отсутствии — генерация UUID v7 на стороне приложения.
